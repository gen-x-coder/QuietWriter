# Security Policy

Meld beveiligingsproblemen niet als publiek issue wanneer publicatie misbruik of gegevensverlies kan vergemakkelijken.

Gebruik voor gevoelige meldingen bij voorkeur GitHub Private Vulnerability Reporting zodra dit voor de repository is ingeschakeld. Als dat niet beschikbaar is, plaats dan een minimaal openbaar issue zonder exploitdetails met het verzoek om een privé contactkanaal.

Ondersteunde versie voor beveiligingsfixes:

- nieuwste stabiele QuietWriter-release.

Vermeld bij een melding indien mogelijk de versie, het platform, de impact en reproduceerbare stappen zonder echte geheimen, API-sleutels of persoonlijke gegevens mee te sturen.
