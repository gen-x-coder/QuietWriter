# QuietWriter 1.5.0-dev.21

Deze ontwikkelversie herstelt het Windows-buildproces: na een geslaagde PyInstaller-build kan de portable ZIP-verpakker weer worden uitgevoerd als zelfstandig script. De fout `ModuleNotFoundError: No module named 'quietwriter'` is verholpen. Een nieuwe subprocess-regressietest bewaakt deze uitvoering.

De updater, schrijfgegevens en gebruikersinstellingen zijn niet gewijzigd. De productie-updater is nog niet geactiveerd.
