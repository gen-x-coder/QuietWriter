# QuietWriter 1.4.0-dev.8 — Een vangnet met een deur erin

Je boeken veiligstellen kon al. Vanaf nu kun je vanuit Instellingen ook rechtstreeks een back-up kiezen om terug te zetten. Het bestaande boek wordt nooit stilletjes vervangen.

Gaat een back-up een keer niet goed? Dan blijft de melding bij het boek zichtbaar, totdat een volgende poging lukt. Geen verrassingen onder het tapijt.

Deze versie is bedoeld om op Windows te testen. De gewone README hebben we met rust gelaten.

De automatische back-ups van de vorige versie blijven optioneel en werken zolang QuietWriter openstaat.
