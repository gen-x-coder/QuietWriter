# QuietWriter 1.4.0-dev.1 — Back-ups op de tekentafel

Een boek mag spannend zijn. Het kwijtraken ervan liever niet.

We hebben uitgewerkt hoe QuietWriter straks zelfstandig veilige kopieën van je boek kan maken, zonder je tijdens het schrijven lastig te vallen. Deze ontwikkelversie bevat het ontwerp; **automatische back-ups zijn nog niet beschikbaar**.
