# QuietWriter 1.4.0-dev.17

## Spelling zonder eindeloze denktijd

Een ongewoon lang woord kan voortaan minder lang de suggestiemachine bezighouden. En wie meerdere woordenboeken heeft, kan bij **Instellingen → Spelling** zelf kiezen welke wordt gebruikt. QuietWriter onthoudt die keuze.

De back-ups en herstelfuncties uit 1.4 blijven behouden. De publieke 1.3.1-hotfix is gericht verwerkt, zonder nieuwere schermen te vervangen.
