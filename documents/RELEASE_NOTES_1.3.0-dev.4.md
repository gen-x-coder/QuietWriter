# QuietWriter 1.3.0-dev.4

Deze ontwikkelbuild verfijnt de nieuwe Neo-boekenplank op basis van de eerste Windows-visuele test.

- Boeken lopen binnen een plank door naar een volgende rij; er is geen horizontale scrollbar meer.
- **Boekacties** is nu een duidelijke brede knop onder **Openen**.
- Bevestigingsvensters voor plank verwijderen/resetten tonen vertaalde **Ja/Nee**-knoppen.
- Het gegevensmodel en de sync/privacybasis zijn niet gewijzigd; `library.json` blijft de centrale bron voor de plankindeling.

Visueel te testen op Windows: responsief omslaan van kaarten bij vensterbreedte, uitlijning van de twee boekknoppen, en de vertaalde bevestigingsdialoog.
