# QuietWriter 1.3.0-dev.2

Deze ontwikkelbuild verstevigt bewust eerst het boekenplankfundament voordat de nieuwe interface erop wordt gebouwd.

De belangrijkste wijzigingen zijn fouttolerantie rond `library.json`, veilige Demo-modus bij ontbrekende of nieuwere plankmetadata, best-effort koppeling van boekoperaties aan de plankindeling, deterministische migratie en betere bescherming tegen gelijktijdige schrijvers.

Er is nog geen nieuwe boekenplank-UI in deze build. De volgende stap kan daarop voortbouwen nadat deze laag gericht is gecontroleerd.
