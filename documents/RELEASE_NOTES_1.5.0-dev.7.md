# QuietWriter 1.5.0-dev.7

Een lokaal testlab voor updates: een Python-testserver biedt een ondertekende nepupdate aan en een geïsoleerde test-updater vervangt uitsluitend nep-programmabestanden. Een foutinjectie laat zien dat eerdere bestanden teruggezet worden. De gewone QuietWriter-installatie blijft onaangeraakt.

**English**

Local update testing tools: a Python test server publishes an ephemeral signed mock package. A disposable updater fixture demonstrates replacement and rollback without touching any real installation. Production installation is not enabled.
