## Blijf schrijven

QuietWriter is een lokale schrijfomgeving voor boeken en langere teksten.

Je manuscript, hoofdstukken, scènes, planning, personages, losse eindjes en versiegeschiedenis zitten bij elkaar. En als je iemand wilt laten meelezen, is daar de optionele AI Meelezer.

Geen account. Geen abonnement. Geen cloud waar je boek per se naartoe moet.

Je boek is van jou.

### Wat kost het?

Niets.

Geen proefperiode. Geen *Premium Writer Pro Plus*-pakket waarin de knop die je nodig hebt toevallig wel zit.

QuietWriter is vrije software onder de GPLv3.

## Hoe heette die straat ook alweer?

Je zit midden in een scène en ineens weet je het niet meer.

Hoe heet die bakker? Wanneer was die verjaardag? Had Bram nou een blauwe of een groene auto?

![Open punten in QuietWriter](branding/screenshots/02-open-punten.png)

QuietWriter houdt bij waar je nog naar terug moet. Later krijg je het wel weer met jezelf aan de stok.

## Weet waar je heen wilt. Of zoek het onderweg uit.

Niet iedereen schrijft hetzelfde.

![Planning in QuietWriter](branding/screenshots/05-planning-personages.png)

![In dit hoofdstuk](branding/screenshots/04-in-dit-hoofdstuk.png)

## AI die weet wanneer hij zijn mond moet houden

QuietWriter heeft een **AI Meelezer**.

Geen AI-schrijver.

De Meelezer kan feedback geven, inconsistenties zoeken, feiten controleren en rekening houden met je boek, personages en schrijversprofiel.

Maar je verhaal schrijven doet hij niet.

![AI Meelezer in QuietWriter](branding/screenshots/03-meelezer.png)

Vraag hem gerust:

> **Eerlijk antwoord: is de kat de dader?**

Het juiste antwoord blijft:

> *Dat ga ik niet voor je verzinnen — het is jouw boek.*

Je kunt de Meelezer gebruiken via een lokaal model met Ollama of via OpenRouter.

Geen zin in AI?

Zet hem uit.

QuietWriter blijft verrassend genoeg gewoon een schrijfprogramma.

## Een boek is geen goed moment om data kwijt te raken

Schrijven kost tijd.

Soms belachelijk veel tijd.

QuietWriter bewaart daarom versiegeschiedenis en heeft herstelvoorzieningen voor wanneer er iets misgaat.

![Versiegeschiedenis in QuietWriter](branding/screenshots/08-versiegeschiedenis.png)

Je kunt eerdere versies bekijken en herstellen. Een compleet boek kan bovendien worden opgeslagen als één overdraagbaar `.qwbook`-bestand, inclusief controles om problemen bij import te ontdekken.

Je manuscript wordt lokaal opgeslagen. QuietWriter heeft geen account nodig om bij je eigen boek te mogen.

## QuietWriter hoeft niet alles te kunnen

Dat is geen ontbrekende feature.

Er bestaan fantastische programma's voor worldbuilding, databases, grafische vormgeving, desktop publishing en ongeveer alles wat ooit zijdelings met een boek te maken heeft gehad.

QuietWriter probeert ze niet allemaal te vervangen.

Een nieuwe functie moet het **schrijven, plannen, reviseren of afronden van een boek merkbaar beter maken**.

Anders is de kans groot dat we hem niet bouwen.

Meer knoppen is makkelijk.

Minder software voelen is moeilijker.

## Broncode

QuietWriter is geschreven in Python met PySide6.

Voor ontwikkeling heb je Python 3.12 of nieuwer nodig.

```bash
git clone https://github.com/gen-x-coder/QuietWriter.git
cd QuietWriter

python -m venv .venv
```

Windows:

```cmd
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

De ontwikkelomgeving is niet hetzelfde als de Windows-release. Voor normaal gebruik hoef je Python niet te installeren.

## Privacy en AI

QuietWriter werkt lokaal en vereist geen account.

Als je **Ollama** gebruikt, kan de Meelezer volledig lokaal draaien.

Gebruik je **OpenRouter**, dan worden alleen de gegevens die nodig zijn voor je bewuste AI-vraag naar de gekozen externe dienst gestuurd. QuietWriter stuurt niet op eigen initiatief je complete manuscript naar een AI-provider.

De Meelezer mag analyseren en feedback geven.

Hij mag niet stiekem besluiten dat hoofdstuk zeven beter kan en het zelf herschrijven.

Zie `PRIVACY.md` voor de volledige uitleg.
