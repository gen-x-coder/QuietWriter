QuietWriter 1.3.1 release snapshot

Application version: 1.3.1
Stable public release before promotion: 1.3.0
Branch: release/1.3.1

1.3.1 scope:
- fixes the spelling-panel hang caused by unbounded spylls edit suggestions for pathological or very long unknown words;
- applies a one-second budget to the expensive edit-candidate phase, then allows faster ngram/fallback suggestions to continue;
- includes a regression test that would hang on the old implementation;
- keeps the new dictionary-source selector for Bundled, ONLYOFFICE, LibreOffice, OpenOffice and user-added compatible Hunspell dictionaries;
- persists spell_dictionary_source with safe fallback when a provider disappears;
- records the semantic handoff required for the already-active 1.4 development line.

Release discipline:
- build the Windows portable binary from this branch;
- if tests and the Windows build are green, test that exact ZIP on Windows;
- do not rebuild after acceptance unless code changes.

README.md and README_EN.md are intentionally unchanged.
