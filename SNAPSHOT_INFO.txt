QuietWriter 1.3.1 hotfix development snapshot

Application version: 1.3.1-dev.1
Stable public release: 1.3.0
Branch: release/1.3.1-dev1

Purpose:
- investigate a reported Windows hang/crash when opening spelling with the bundled Dutch Hunspell dictionary;
- expose an explicit dictionary-source selector so the same machine can switch between discovered providers for one language;
- keep the 1.3.1 patch isolated from ongoing 1.4 development.

1.3.1-dev.1 scope:
- DictionaryCatalog retains multiple providers for the same locale.
- Settings > Spelling has separate Language and Dictionary controls.
- Supported selectable sources are Bundled, ONLYOFFICE, LibreOffice, OpenOffice and user-added compatible Hunspell dictionaries.
- The selected source is persisted as spell_dictionary_source.
- If that provider disappears, QuietWriter falls back to the legacy preferred provider for the same locale.
- Existing users without the new setting keep the old provider-priority behaviour.
- HOTFIX_1.3.1_SPELLING_TRANSFER.md records the semantic changes that must later be ported into the 1.4 line.

Important:
- This dev build does not claim the root cause of the reported crash is fixed.
- The selector is deliberately both a diagnostic tool and a practical fallback.
- Microsoft Office is not advertised as a full Hunspell provider; QuietWriter only lists dictionary formats/sources it actually supports.

README.md and README_EN.md are intentionally unchanged.
