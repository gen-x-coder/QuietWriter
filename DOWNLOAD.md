# QuietWriter downloaden

De officiële QuietWriter-releases worden gepubliceerd via GitHub Releases:

https://github.com/gen-x-coder/QuietWriter/releases

Voor Windows is de nieuwste stabiele portable versie beschikbaar via:

https://github.com/gen-x-coder/QuietWriter/releases/latest/download/QuietWriter-windows-portable.zip

Pak de ZIP volledig uit voordat je QuietWriter start.

## Code signing

QuietWriter gebruikt voor officiële Windows-releases de code-signing-infrastructuur van SignPath zodra de open-source signingconfiguratie actief is.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

De broncode, buildworkflow en code-signing policy zijn openbaar beschikbaar in deze repository. Zie ook `CODE_SIGNING_POLICY.md`.
